## What I do

- **Offensive security**: web and API pentesting, bug bounty hunting, DAST tooling
- **Builder**: desktop tools for AI coding CLIs, scanners, fuzzing benchmarks, rate-limit testers
- **Bright Security**: scan engineering, authentication objects, repeater scripts, log forensics

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**Husk**](https://github.com/DorShaer/Husk) | Desktop home for your CLI agent. Wraps claude / copilot / codex / aider in an Electron window with PTY, MCP, drag-drop context, sessions, voice, and a live status panel. | TypeScript, Electron |
| [**pyrate**](https://github.com/DorShaer/pyrate) | Tests endpoints for missing or weak rate limiting. | Python |
| [**bruno-export-tool**](https://github.com/DorShaer/bruno-export-tool) | Converts Bruno API collections to Postman and OpenAPI 3.0. | JavaScript |
| [**cardparse**](https://github.com/DorShaer/cardparse) | Deliberately vulnerable `.card` parser, used as a fuzzing benchmark for Bright Agent. | C++ |
| [**KeyChecker**](https://github.com/DorShaer/KeyChecker) | Checks a leaked Google API key against Google's paid services. | Python |
| [**QRadar_resolve_sid**](https://github.com/DorShaer/QRadar_resolve_sid) | SID resolution helper for QRadar integrators. | Python |
